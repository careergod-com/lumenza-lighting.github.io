# ✦ LUMENZA Lighting

> **Brighter spaces. Better living.**

LUMENZA Lighting is a premium e-commerce storefront concept for contemporary lighting, LED systems, smart illumination, decorative fixtures, architectural lighting and outdoor solutions.

## Included

- Premium black / ivory / warm-gold visual identity
- Responsive homepage
- 12 deterministic product entries
- 8 shopping categories
- Search and category filtering
- Price sorting
- Wishlist with LocalStorage
- Shopping cart with LocalStorage
- Lighting Finder
- Collections and editorial journal sections
- Smart lighting feature section
- Support/contact section
- Responsive mobile layout
- Local LUMENZA logo asset

## Product image note

Product imagery is mapped explicitly to each product. The storefront keeps product names, prices, badges, favorite controls and cart controls outside the photographs. Several demo product photographs are loaded from their original public image URLs for this concept; replace them with properly licensed/local production assets before commercial deployment.
