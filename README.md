# LUMENZA Lighting — V3

A richer static ecommerce storefront for contemporary lighting, built for GitHub Pages.

## What changed in V3
- Expanded editorial homepage with room-based shopping, collections, studio section and trust content.
- 12 local product renders with one consistent background per image and no embedded UI/text.
- 8 local category visuals plus room, collection and editorial scenes.
- Product cards, detail pages, cart and wishlist remain functional.
- No runtime dependency on remote product photography.
- 80+ project files/assets for a fuller, less template-like storefront.

## Technologies
HTML5 · CSS3 · Vanilla JavaScript · SVG assets · JSON

## Status
Project in development / portfolio storefront demo.
