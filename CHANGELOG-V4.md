# LUMENZA Lighting — V4

## Realistic Photography Edition

V4 keeps the V3 layout and interaction model while replacing the abstract/SVG visual system with locally stored realistic lighting photography generated for the LUMENZA art direction.

### Changes
- Replaced all 12 product SVG visuals with realistic JPG photography.
- Replaced all 8 category SVG visuals with realistic JPG photography.
- Replaced room/hero scene art with realistic editorial interior photography.
- Added smart-lighting, outdoor-lifestyle and collection photography assets.
- Product cards use one continuous media background; no nested image-frame effect.
- All visual assets are local to the ZIP for deterministic GitHub Pages deployment.
