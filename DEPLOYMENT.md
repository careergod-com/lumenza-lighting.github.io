# LUMENZA V3 Deployment

1. Upload the complete folder to GitHub Pages.
2. Keep the folder structure unchanged.
3. All product and scene visuals in V3 are local SVG assets; the storefront does not require remote product-image URLs.
4. Open `index.html` to preview locally.
5. Product pages live under `pages/`.

## Visual system
- One unified background per product render.
- Product-only visuals: no baked-in prices, buttons, hearts or product names.
- Room scenes are separate editorial assets from product renders.
- UI typography and controls remain outside imagery.
