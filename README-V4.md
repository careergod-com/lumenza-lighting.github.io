# LUMENZA Lighting V4

Premium lighting storefront with realistic local photography, product catalog, category browsing, collections, smart lighting, journal, support, cart and wishlist interactions.

## Photography
The V4 package uses locally stored generated photography for products, categories and editorial scenes. Each catalog item is mapped explicitly to its own image asset.

## Deployment
Upload the contents of this folder to a GitHub Pages repository. No external image host is required for the included photography.

## Technologies
HTML5 · CSS3 · JavaScript · JSON · Local JPG assets
