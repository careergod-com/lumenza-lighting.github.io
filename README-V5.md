# LUMENZA Lighting — V5

V5 keeps the complete LUMENZA storefront structure from V4 while focusing this release specifically on product-image clarity and presentation. The catalog now points to sharper product photography, product cards use contain-style framing to avoid cropping, and each product keeps an explicit deterministic image assignment.

## Included
- Multi-page ecommerce storefront
- 12 catalog products
- High-quality product image mapping
- Product detail pages
- Search, filtering and sorting
- Cart and wishlist
- Collections, rooms and smart lighting sections
- Support and FAQ
- Responsive layout
- Local fallback image assets retained in the ZIP

## Important
The demo references external product-photography URLs for the upgraded image quality. For a commercial deployment, replace them with images you have permission to distribute.
